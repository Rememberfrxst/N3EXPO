# UI reference screenshots

Upload screenshots here using **Add file → Upload files** on GitHub.

Suggested names:

- `home.jpg` — Home screen and banners
- `product.jpg` — Product detail screen
- `me.jpg` — Me/profile screen
- `category.jpg` — Category screen
- `admin.jpg` — Admin panel, if applicable

For multiple references, use names such as `home-01.jpg` and `home-02.jpg`. PNG and WebP files are also welcome.
